# منارات — منصة مراكز تحفيظ القرآن

**منارات** منصة مجانية (موقع + تطبيق PWA يُثبَّت على الجوال ويعمل بدون إنترنت) تسجّل فيها مراكز
تحفيظ القرآن، وكل مركز يدير حلقاته وطلابه ومعلّميه بمعزل تام عن غيره.

- كل مركز: صفحة عامة برابطه، شعاره وألوانه، ونموذج تسجيل لأولياء الأمور.
- متابعة الحفظ والتلاوة والمراجعة والتلقين والحضور، وتقارير شهرية وشهادات وتصدير Excel.
- أدوار: صاحب المركز يدعو المدراء والمعلّمين بالبريد.
- عزل البيانات بين المراكز على مستوى قاعدة البيانات (Supabase RLS).

> انفصلت المنصة عن مشروع «مركز مضايا» (`oz819/madaya`) في 2026-11-11. تاريخ git محفوظ كما هو،
> وشرح البنية الأصلي في `docs/README-madaya-origin.md` و`docs/SAAS.md`.

## التشغيل محليًا (نسخة تجريبية ببيانات وهمية، بلا قاعدة حقيقية)

```bash
npm install
NEXT_PUBLIC_DEMO=1 NEXT_PUBLIC_SUPABASE_URL=http://localhost:3000/sb \
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=demo-anon-key SUPABASE_SERVICE_ROLE_KEY=demo-service-key \
npx next dev
```

الدخول: `admin@demo.com` بكلمة المرور `demo1234` (أو الرمز `123456`).

## الاختبارات

```bash
npm run test:db   # عزل المراكز والصلاحيات وطلبات التسجيل (PGlite)
npx tsc --noEmit && npx eslint .
```

## الهوية والواجهة الرئيسية

- **كحلي وذهبي:** الواجهة الرئيسية (`components/center/PlatformLanding.tsx` و`app/landing.css`) فيها الآتي:
  - واجهة ليلية ثلاثية الأبعاد (مسجد ومصحف وفوانيس) مع النجمة المتحركة ثلاثية الأبعاد (`StarField`).
  - جوالين، ولوحة إدارة المركز، والمميزات، ومخطط النظام، والهوية، وكيف تبدأ، وخريطة الحفظ، وسجّل مركزك.
  - توقيع المطوّر (إنستغرام) بنص أسفل الصفحة.
- **الشعار:** قوس ونجمة فوق كتاب مفتوح (`ManaratMark`)، ومنه أيقونات التطبيق في `public/icon-*.png` و`app/icon.png`.
- **صورة الواجهة ثلاثية الأبعاد:** مكانها `public/landing/hero.webp`. لحد ما تنحط، بتظهر الرسمة البديلة `public/landing/hero-scene.svg`.

## الفصل عن مضايا

- **منفصل بالكود:**
  - البيانات التجريبية صار مركزها «مركز النور» (رابطه `/noor`) بدل مضايا.
  - مخزن النسخة التجريبية صار `manarat-demo`.
  - ملفات النسخ الاحتياطي صارت `manarat-…`.
  - `.env.local.example` ما فيه قاعدة مضايا.
- **قيد العمل:**
  - **قاعدة البيانات:** قاعدة Supabase مستقلة للمنصة، لأنه ملفات الترحيل الحالية ما زالت تبني على قاعدة مضايا (`supabase/migrations/20261101100000_multi_center.sql` بتنشئ مركز مضايا كأول مركز). مشروع جديد بده ترحيل أساسي نظيف بدون بيانات مضايا.
  - **النطاق:** نطاق خاص بالمنصة.
